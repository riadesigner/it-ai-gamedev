# День 2. Реализация игры

Задание дня состоит из трех частей

## Часть 1 - первая реализация на основе GDD

Задача - реализовать игру на js/html/canvas на основе GDD из day-01

Условие - обязательно использовать две разные (любые) модели и в конце сравнить результат. 

Лучший результат - сдать в конце дня. А ваше сравнение моделей - опишите в файле **game-1-readme**


## Как начать работу

### Шаги

1. Скопируйте [стартер](../examples/starter/index.html) → `day02/index.html`.
2. Объясните LLM что хотите получить на выходе.


**Подсказка**: на выходе от LMM вы хотите получить один файл index.html, в котором будет реализована игра на html/js/canvas 


## Часть 2 - идеация с LLM, усложнение игры

10 идей c LLM - как можно улучшить, усложнить механику игры. Лучшие  - реализовать.
Например: джобавить порталы, очки, игру на время, ускорение, частицы (particles)


## Часть 3 - текстуры и звук

Добавить текстуры на фон или стены.

## Что сдать в конце дня

два файла


| Файл             | Зачем                                            |
| ---------------- | ------------------------------------------------ |
| `game.html`     | законченная игра по ТЗ из первого дня |
| `game-full.html`     | законченная игра со звуком, текстурами и улучшеной механикой |
| `картинки, звуки`     | дополнительные необходимые файлы для законченной игры |
| `game-readme.md` | внутри – ваш первый промпт, который вы дали LLM для создания игры, и сравнение моделей, какие лучше справились, какие с первого раза |
