# Неделя 1. Первый GDD с помощью LLM

Код игры **не пишем**. Используем ИИ в работе — но финальный текст правите сами и можете его объяснить и защитить.

## Что сдать

Папка `week01/`: файл `**week01-gdd.md**` по шаблону ниже.

На паре: за ~1 минуту — пич и 3 состояния врага, своими словами.

## Что сдаем

GDD - Описание игры с условиями:

- одноэкранная игра, 1 игрок, 1 тип врага;
- враг = состояния `patrol` / `chase` / `attack` (конкретные состояния);
- объем игры такой, чтобы для ее реализации потребовалось не больше несколько практик;
- есть блок «Что сделал ИИ / что изменил я»;
- вы объясняете GDD без чата.

**Что не нужно создавать и сдавать:** код, спрайты, картинки.

## Как сделать

1. Выбрать две любые LLM (ниже на выбор).
2. Поработать в каждой с LLM (≥ 3 итерации).
3. Получить в них два разных GDD (по условиям выше)
4. Самим что-то переписать в финале.
5. Взять шаблон файла `week01-gdd.md`и заполнить своим содержанием.
6. Созранить you-surname-week01-gdds-01.md, you-surname-week01-gdd-02.md

- [ ] Чат: DeepSeek / Qwen / GigaChat
- [ ] Папка `week01/`, файл `week01-gdd.md` по шаблону

### B. Три итерации

**1. Черновик промпта** — вставьте в LLM, ответ перенесите в `week01-gdd.md`:

```text
Ты — геймдизайнер мини-игр.
Составь короткий GDD одноэкранной 2D-игры на 5–10 минут.
Без кода и длинного лора — только механика.

Ограничения:
- top-down или платформер
- 1 игрок, 1 тип врага, без сети
- реализуемо студентом 2 курса за 2–4 практики

Структура ответа:
1. Название
2. Пич (1 предложение)
3. Цель игрока
4. Управление
5. Враг: 3–5 пунктов как конечный автомат
6. Победа / поражение
7. Позже (макс. 3 пункта)
```

**2. Пример промпта, чтобы уменьшть объем** игры — подставьте свой GDD вместо `{вставить}`:

```text
Вот мой GDD:
---
{вставить}
---
Вырежи всё, что нельзя сделать за 3 практики студенту 2 курса.
Оставь одноэкранную игру. Ответ — только обновлённые секции.
```

Объем игры = что делаем сейчас, а что нет.

**3. Пример промта для врага (Враг как FSM):**

```text
Опиши врага только как конечный автомат:
состояния: patrol, chase, attack.
Для каждого: вход, что делает каждый тик, выход.
Без лишней прозы.
```

Обновите секцию врага в GDD.

**Обязательно самим:** укоротить пич, убрать лишнюю механику или оставить ровно 3 состояния врага.

**По желанию:** 2–3 предложения — что будет классическим game AI, генеративным контентом, и где будет использоваться (использована) LLM.

## Шаблон `week01-gdd.md`

```markdown
# Название

## Пич (1 предложение)

## Цель игрока

## Управление

## Враг (состояния)

- patrol:
- chase:
- attack:

## Победа / поражение

## Что можно добавить позже (макс. 3)

## Что сделал ИИ / что изменил я

## Модель и дата
```



## Термины


|                |                                       |
| -------------- | ------------------------------------- |
| **GDD**        | как устроена игра (не код)            |
| **Пич**        | одно предложение: во что играют       |
| **Объем игры** | рамки: что делаем сейчас              |
| **FSM**        | режимы врага: patrol → chase → attack |
| **LLM**        | чат с моделью (DeepSeek, Qwen…)       |




## Частые ошибки

- слишком большой дизайн, «умный» враг без состояний;
- сырой ответ чата без правок и без «ИИ / я»;
- не можете объяснить пич и переходы врага.
