# Грубый план семестра (набросок)

Статус: черновик для обсуждения. Детали ДЗ и конспектов — позже.

## Модули

### М0. Старт и правила (неделя 1)

- Что такое «ИИ в играх» vs ChatGPT
- Честность: блок «ИИ / я» в артефакте, границы сдачи
- Сетап: DeepSeek/Qwen/GigaChat, Cursor, браузер, Godot
- Демо: за ~20 мин с ИИ набросать дизайн одноэкранной игры (только текст)

Подробно (преподаватель): [week-01.md](./week-01.md)  
Задание для студентов (GitHub): [../assignments/week-01/README.md](../assignments/week-01/README.md)

### М1. ИИ как копилот разработчика (недели 2–3)

- Промпты под код/баги; когда ИИ врёт
- Web: canvas (игрок + препятствия) с копом; студент объясняет функции
- Godot: Hello World 2D, сцена, скрипт, ввод

### М2. Классический game AI (недели 4–7)

- FSM врага (патруль → погоня → атака)
- Steering / seek-flee
- Сетка + BFS или упрощённый A*
- Behaviour trees — идея и схема, без тяжёлой реализации
- Сначала canvas/JS, потом тот же FSM в Godot

### М3. Генеративный контент и пайплайн (недели 8–11)

- Текст: квесты, нейминг, лор, диалоги (шаблоны + LLM)
- Картинки: концепт → спрайт (доступные в РФ сервисы); лицензии
- Blender: роль ИИ в пайплайне, простой low-poly проп → экспорт
- ProcGen: комнаты/коридор на сетке
- three.js обзорно: одна сцена «модель + свет»

### М4. LLM внутри игры (недели 12–14)

- NPC через API + жёсткий fallback без сети
- Галлюцинации, задержки, модерация, стоимость
- Опционально для сильных: мини-RAG по lore.md
- Сравнение: агент в IDE vs ИИ в рантайме игры

### М5. Мини-проект и защита (недели 15–18)

Треки на выбор:

- **A:** Godot 2D + классический ИИ (FSM/path)
- **B:** Web canvas/three + ProcGen или LLM-NPC
- **C:** Пайплайн ассетов (Blender + генеративка) + встройка в простой билд

| Неделя | Фокус |
|--------|--------|
| 15–16 | Сборка в практиках |
| 17 | Playtest + доработка |
| 18 | Защита 5–7 мин: направление ИИ, что сам, чему научился |

## Формат пары (ориентир)

- **Лекция:** обзор идей + 1–2 демо «показать руками»
- **Практика 1:** повторить / собрать каркас
- **Практика 2:** вариация / мини-челлендж / рефлексия «что ИИ, что я»
- Домашка — лёгкая; основное — в аудитории
