# Старт: «ИИ в игровой разработке»

Выжимка контекста и согласованных решений. Читать в начале любой сессии по курсу.

## Аудитория

- Колледж, Россия. Студенты **16–18 лет**, обучение **3 года**.
- Предмет ведётся для **2 курса** (программирование уже начато: JS, Python, C# — всё ещё базово).
- Есть также 1 курс; фокус материалов — на 2-й.

## Преподаватель (я)

- Web-fullstack: vanilla JS, Node.js, React, Postgres, nginx, Linux.
- Немного Python (скрипты).
- Blender, web-design.
- Cursor: агенты и skills.
- **Unity / Godot / Unreal ещё не знаю** — учу параллельно со студентами, на шаг впереди.

## Ограничения по инструментам (РФ)

Доступны (бесплатно / относительно доступно):

- DeepSeek, Qwen, GigaChat
- Возможно DeepSeek → Visual Studio через Cline (уточнить при сетапе)

Unity и Unreal — **не в этом семестре** (оставить на будущее).

## Нагрузка семестра

- **18 недель**
- В неделю: **1 лекция + 2 практики**
- Каждая пара: **1,5 часа**
- Итого контакт ≈ 81 ч

## Философия курса (главное решение)

**Не цель:** «выучить Godot/Unity за семестр».  
**Цель:** показать **полезность разных видов ИИ** в играх на живых примерах; движки — только полигон.

Итог для студента: видел несколько видов ИИ, сделал 3–4 мини-демо, понимает куда копать дальше.

## Полигон (чем делаем демо)

| Роль | Выбор |
|------|--------|
| Основной быстрый старт | **Web**: canvas → обзор three.js |
| Игровой движок | **Godot 2D** (GDScript ближе к Python/JS) |
| 3D-пайплайн | **Blender** (не курс 3D, а звено ассетов + ИИ) |
| Отложено | Unity, Unreal |

Черновик баланса времени: ~40% web / ~35% Godot / ~15% Blender+ген / ~10% итоговый проект.

## Три вида «ИИ» (не смешивать на лекции без ярлыка)

1. **Классический game AI** — FSM, steering, pathfinding, обзор BT/utility  
2. **Генеративный контент** — текст, картинки, звук, ProcGen, Blender-пайплайн  
3. **LLM и агенты** — диалоги NPC через API, ИИ-копилот в IDE, помощь в дизайне/тестах  

Инструменты студента: DeepSeek / Qwen / GigaChat + Cursor (или Cline) как **напарник**, не магия.

## Принципы преподавания (чтобы не утонуть)

1. Один глубокий полигон за раз: web чиню быстро; Godot — на 1–2 недели впереди; three.js — 1–2 занятия.
2. Каждая практика = **один артефакт**, не «изучить движок».
3. ИИ всегда в кадре (даже на FSM: ИИ набросал таблицу состояний — студент закодил переходы).
4. Офлайн-план B при сбоях API (шаблоны, заготовки, «как было бы с API»).
5. Не обещать обучение нейросетей / ML training — только API + классика.

## Честность и сдача

- Явное в артефакте: что сделано самим, что с ИИ.
- Студент должен **объяснить** код, который писал с копом.
