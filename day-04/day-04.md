# День 4 (встреча 4) — Генспрайты + canvas: свой герой, своя сцена

**Модуль:** М1. ИИ как копилот + **генеративный контент**  
**Задание для студентов:** [tasks/task-04.md](./tasks/task-04.md)  
**Цель встречи:** студенты генерируют спрайт персонажа (image-ИИ) и собирают **отдельную** canvas-сцену с анимацией idle/run — только промптами, **без открытия кода**.

**Итог дня (артефакт):** `day04/index.html` + `day04/assets/*.png` + `day04-notes.md` (журнал промптов).

**Важно:** это **не** продолжение day02 и **не** GDD дня 1. Отдельный мини-проект после трёх дней с одной игрой.

**Связь с курсом:** на доске — **второй вид ИИ** (генконтент: картинки). Дни 1–3 — текст и код; сегодня — ИИ рисует ассеты.

## Пара 2 (1,5 ч) — практика в двух частях

### Цель пары

- **Ч.1:** мини-бриф → `hero-idle.png` + `hero-run-sheet.png`
- **Ч.2:** `day04/index.html` — движение + анимация idle/run

### Результат к концу пары

**Часть 1 (~45 мин)**

- [ ] Бриф персонажа в notes  
- [ ] 2 PNG в `day04/assets/`  
- [ ] ≥ 2 итерации промпта image-ИИ зафиксированы  

**Часть 2 (~45 мин)**

- [ ] F5: герой — спрайт, не квадрат  
- [ ] Стоит — подпись `idle`; движется — `run`  
- [ ] Журнал промптов копилота в notes  

**Критерий «зачтено»:** playtest-чеклист пройден; журнал промптов; устно — показать idle/run и прочитать лучший промпт.

**Не требуется:** JS, открытие кода, связь с GDD, враг, FSM.

### Ход пары

| Мин   | Часть | Что делаем                                      |
| ----- | ----- | ----------------------------------------------- |
| 0–10  | 1     | Заполнить бриф персонажа                        |
| 10–35 | 1     | Gen idle + run; 2 итерации промпта              |
| 35–45 | 1     | PNG в `assets/`, чек: оба узнаваемы как один герой |
| 45–55 | 2     | Промпт 1: каркас canvas                           |
| 55–70 | 2     | Промпт 2: подключить спрайты, idle/run            |
| 70–85 | 2     | Фиксы-симптомами; журнал промптов                 |
| 85–90 | —     | Сдача                                           |

### Промпты для доски

**Image-ИИ (idle):**

```text
2D game character sprite, pixel art, side view facing right.
Character: {имя} — {1 фраза}. Visual: {набросок-рисунок}.
Pose: standing idle. Plain solid background #00FF00. No text, no watermark.
```

**Image-ИИ (run):** тот же бриф, pose: running mid-stride (или 2–3 кадра в ряд).

**Копилот — каркас:**

```text
Создай day04/index.html: canvas 640×480, WASD, серый квадрат-placeholder по центру.
Один файл, без библиотек. Сначала план, потом код.
```

**Копилот — спрайты:**

```text
В day04/index.html подключи assets/hero-idle.png и assets/hero-run-sheet.png.
Стоит — idle. WASD — run (2–3 кадра). Подпись анимации на экране: idle / run.
```

### Типичные сбои

| Проблема | Промпт-симптом |
| -------- | -------------- |
| Разный герой на idle и run | «Same character: {бриф}. Перегенери run.» |
| Спрайт огромный | «Отображай героя 48×48 пикселей на canvas» |
| Нет idle/run переключения | «При отпускании WASD — idle, при движении — run» |
| Студент лезет в day02 | «Day04 — отдельная папка, day02 не трогаем» |

### Дифференциация

- **Базовый:** idle + run, однотонный фон  
- **Средний:** + `background.png`; flip при движении влево  
- **Быстрый:** + прыжок (Space); декоративный второй персонаж
