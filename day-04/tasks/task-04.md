# День 4. Автосалон 3д

## Задание

Создать веб-страницу 3д автосалон по продаже автомобилейс презентацией трех автомобилей.

## Технологии

- html/js/css, threejs - основа
- exr (hdr) карта - для фона и отражений
- glb (gltf+textures)
- Live Server (Ritwick Dey)

## Визуальныей стиль

- темная тема + один акцентный цвет
- три источника освещения (Key, Fill, Rim)
- сферический фон с адаптированной hdri текстурой
- информационные панели (положение камеры, угол поворота подиума)
- панель управления освещением
- кнопки переключения 3д моделек, кнопки поворота подиума и камеры
- черный зеркальный подиум по центру с белым кантом
- акцентный светящийся круг вокруг подиума
- размер подиума - 5м, раз автомобилей - 4-5 метров
