# День 4. Спрайты + canvas: свой герой, своя сцена

**Отдельный мини-проект** — не связан с GDD дня 1 и не продолжение `day02/`.

Вы **не открываете код**. Image-ИИ рисует спрайты, копилот собирает сцену, вы **playtest'ите** в браузере и ведёте **журнал промптов**.

---

## Главная идея дня


| Делает человек                         | Делает ИИ                         |
| -------------------------------------- | --------------------------------- |
| Мини-бриф персонажа                    | Рисует idle + run (image-ИИ)      |
| Промпты копилоту (каркас → спрайты)    | Пишет `index.html`                |
| Playtest: idle / run, фиксы-симптомами | Чинит по описанию «вижу / ожидал» |
| Журнал промптов + «ИИ / я»             |                                   |


**Не нужно:** JavaScript, открывать файлы кода.  
**Нужно:** чётко описать *что* на экране и итерировать промпты.

---



## Что сдать

Папка `day04/`:


| Файл / папка     | Зачем                                                     |
| ---------------- | --------------------------------------------------------- |
| `index.html`     | Canvas-сцена с вашим героем                               |
| `assets/`        | `hero-idle.png`, `hero-run-sheet.png` (+ опционально фон) |
| `day04-notes.md` | Бриф, промпты, playtest-чеклист                           |


**На сдаче (~1 мин):** показать idle → run → idle; **прочитать** промпт, которым добились run; одной фразой — кто ваш герой.

---



## Часть 1 — Мини-бриф → спрайты (~45 мин)



### Бриф (заполните в notes)

```markdown
## Бриф персонажа
- Имя:
- Кто это (1 фраза):
- Стиль: pixel art / cartoon / …
- набросок-картинка
```



### Промпт image-ИИ (idle)

```text
2D game character sprite, {стиль}, side view facing right.
Character: {имя} — {1 фраза}. Visual: {набросок-рисунок}.
Pose: standing idle.
Plain solid background #00FF00 for easy removal.
No text, no watermark. Game-ready.
```



### Промпт image-ИИ (run)

```text
2D game character sprite, {стиль}, side view facing right.
Same character: {имя} — {1 фраза}. Visual traits: {2 черты}.
Pose: running mid-stride (or 2–3 running frames in a horizontal strip).
Plain solid background #00FF00. No text, no watermark.
```

Сохраните в `day04/assets/`:

- `hero-idle.png`
- `hero-run-sheet.png`

**Сделайте 2 итерации** промпта (v1 и v2) — запишите, что изменили.

### Критерии ч.1

- [ ] PNG сохранены, персонаж читается  
- [ ] Idle и run **похожи** на одного героя  
- [ ] В notes — оба промпта + сервис (Kandinsky / FusionBrain / …)  

---



## Часть 2 — Сцена через промпты (~45 мин)



### Цепочка промптов (не один «сделай всё»)

**1. Каркас:**

```text
Создай day04/index.html — canvas 640×480, тёмный фон страницы.
WASD / стрелки — движение серого квадрата-placeholder.
Один файл, vanilla JS, без библиотек. Сначала план, потом код.
```

**2. Спрайты:**

```text
В day04/index.html подключи assets/hero-idle.png и assets/hero-run-sheet.png.
Серый квадрат замени на спрайт героя.
Стоит — idle. Движется — анимация run (2–3 кадра).
На экране подпись: idle / run.
```

**3. Фикс-симптом (при необходимости):**

```text
Вижу: {что на экране}.
Ожидал: {idle при остановке / run при движении / …}.
Исправь. Не меняй размер canvas.
```



### Playtest-чеклист

- [ ] F5 открывается  
- [ ] Вижу своего героя (не серый квадрат)  
- [ ] Стою — подпись `idle`  
- [ ] WASD — подпись `run`, персонаж двигается  
- [ ] Отпустил клавиши — снова `idle`

## Частые ошибки


| Неправильно                           | Правильно                                      |
| ------------------------------------- | ---------------------------------------------- |
| Один промпт «сделай игру со спрайтом» | Каркас → спрайты → фикс отдельно               |
| Разные герои на idle/run              | В run-промпт добавить «same character: {бриф}» |
| Открываю код и правлю руками          | Только промпты + F5                            |
| Путаю с day02                         | `day04/` — отдельная папка, day02 не трогаем   |
