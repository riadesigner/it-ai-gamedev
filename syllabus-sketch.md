# Грубый план семестра (набросок)

Статус: черновик для обсуждения. Детали ДЗ и конспектов — позже.

## Формат курса

- **9 встреч** (дней) с преподавателем
- На встречу: **2 пары** по 1,5 ч
- Итого: **18 пар** ≈ **27 ч** контакта (36 ак.ч.)
- Календарно: ~4 пары в неделю → встречи раз в ~3–4 дня (уточнить у расписания)

## Модули

### М0. Старт и правила (день 1)

- Что такое «ИИ в играх» vs ChatGPT
- Сетап: DeepSeek/Qwen/GigaChat, Cursor, браузер, Godot
- Демо: за ~20 мин с ИИ набросать дизайн одноэкранной игры (только текст)

Подробно (преподаватель): [day-01/day-01.md](./day-01/day-01.md)  
Задание для студентов (GitHub): [day-01/tasks/task-01.md](./day-01/tasks/task-01.md)

### М1. ИИ как копилот разработчика (встреча 2–3)

- Промпты под код/баги; когда ИИ врёт
- Web: canvas — ч.1 игрок + стены, ч.2 враг из GDD (копом); карта функций
- Godot: Hello World 2D, сцена, скрипт, ввод

Подробно (преподаватель): [day-02/day-02.md](./day-02/day-02.md)  
Задание для студентов (GitHub): [day-02/tasks/task-02.md](./day-02/tasks/task-02.md)

### М2. Классический game AI (дни 4–6)

- **Превью на дне 2:** враг patrol/chase/attack из GDD на canvas (копилот)
- FSM — теория, таблица переходов, рефакторинг (день 4)
- Steering / seek-flee
- Сетка + BFS или упрощённый A*
- Behaviour trees — идея и схема, без тяжёлой реализации
- Сначала canvas/JS, потом тот же FSM в Godot (день 7)

### М3. Генеративный контент и web (дни 7–8)

- Текст: квесты, нейминг, лор, диалоги (шаблоны + LLM)
- Картинки: концепт → спрайт (доступные в РФ сервисы); лицензии
- Web-ассеты: glTF/спрайты, three.js, ProcGen в браузере

### М4–М5. LLM в игре + мини-проект (день 9)

- NPC через API + fallback без сети; ограничения и безопасность
- Сборка и защита мини-проекта (треки A/B/C)

Треки на выбор:

- **A:** Godot 2D + классический ИИ (FSM/path)
- **B:** Web canvas/three + ProcGen или LLM-NPC
- **C:** Web + генеративные ассеты (спрайты/glTF) + сборка в браузере
