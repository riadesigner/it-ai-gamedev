**Модуль:** М1. Промпт-инженерия (+ классический game AI из day02 как контекст)

## Пара 1 (1,5 ч) — лекция

### Тайминг

| Мин   | Блок                                                              |
| ----- | ----------------------------------------------------------------- |
| 0–10  | Связка: day02 — база; сегодня **расширяем** игру новой идеей      |
| 10–30 | Brainstorm-промпты: роль, ограничения, формат списка              |
| 30–50 | Плохой vs хороший промпт («придумай механики» vs структура)       |
| 50–70 | **Демо:** 10 идей → выбор → промпт копилоту → F5                  |
| 70–85 | Опционально: эскиз в image-ИИ                                     |
| 85–90 | Критерии сдачи                                                    |

### Плохой vs хороший brainstorm

**Плохо:** «Придумай что-нибудь интересное для игры»

**Хорошо:**

```text
Ты — геймдизайнер одноэкранных 2D-игр.
Моя игра: {пич из GDD}. Уже есть: игрок, препятствия, враг (patrol/chase/attack).
Придумай 10 НОВЫХ интерактивных элементов — не из моего GDD.
Формат: номер · название · что делает · как игрок понимает за 1 сек.
Без кода. Минимум 3 необычные идеи.
```

## Пара 2 (1,5 ч) — практика

### Цель пары

- **Ч.A:** 10 идей от LLM, выбор 1, обоснование  
- **Ч.B:** механика работает в day02; старая сцена не сломана  

### Результат к концу пары

**Часть A (~45 мин)**

- [ ] 10 идей в `day03-notes.md`  
- [ ] Выбрана 1 идея + обоснование (1–2 предложения)  
- [ ] Зафиксированы v1 и v2 промпта brainstorm  

**Часть B (~45 мин)**

- [ ] Новая механика видна в браузере  
- [ ] Игрок, стены, враг FSM **как на дне 2**  
- [ ] Журнал промптов внедрения + фиксов  

**Критерий «зачтено»:** playtest-чеклист; устно — показать механику и прочитать brainstorm-промпт.

### Ход пары

| Мин   | Часть | Что делаем                                |
| ----- | ----- | ----------------------------------------- |
| 0–10  | A     | Вставить GDD + «что уже в игре» в промпт  |
| 10–30 | A     | Получить 10 идей; улучшить промпт (v2)    |
| 30–45 | A     | Выбрать 1; опционально эскиз в image-ИИ   |
| 45–50 | B     | Промпт копилоту: добавить механику        |
| 50–70 | B     | Playtest; фиксы-симптомами                |
| 70–85 | B     | Чек: day02 не сломан; журнал промптов     |
| 85–90 | —     | Сдача                                     |

### Промпты для доски

**Brainstorm:**

```text
{шаблон из лекции — пич + что уже есть}
```

**Внедрение:**

```text
В day02/index.html работают: игрок, препятствия, враг (3 состояния). Не ломай их.

Добавь новую механику:
---
{выбранная идея из списка 10}
---
На экране должно быть видно, что работает (подпись, счётчик, эффект).
Сначала план из 3 шагов, потом правки.
```

**Фикс:**

```text
После добавления механики: вижу {…}, ожидал {…}.
Враг/игрок/стены должны работать как на дне 2. Исправь.
```

### Примеры идей (если LLM слабый)

- Зона замедления (синий круг)  
- Платформа исчезает через 2 сек после наступления  
- Бонус: 3 сек враг не переходит в chase  
- Телепорт-ловушка в угол арены  

### Дифференциация

- **Базовый:** 1 механика работает  
- **Средний:** + эскиз в image-ИИ  
- **Быстрый:** + 2-я идея из топ-10; сравнить brainstorm двух LLM
