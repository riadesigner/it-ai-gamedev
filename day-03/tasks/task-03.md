# День 3. Спрайты + canvas: свой герой, своя сцена

### Задание из 3-х частей

## 1. робот (скетч 2 рендер)

- рисуем скетч робота (с преподом)
- на основе скетча создаем качественный рендер 3д (gemini / gigachat)
- сравниваем результат
- рисуем своего персонажа (скетч). Преобразуем в качественный 3д рендер.
- показываем его со всех сторон.
- анимируем (qwen | alisa)
- пробуем создать спрайт

## 2. спрайт

- берем готовый спрайт 2д  персонажа, который бежит.
- создаем index.html + управление персонажем вправо / влево / прыжок.
- создаем два экрана своей локации
- собираем в одну игру с двумя экранами и переключениями мужду ними.
- добавляем эффект (дождь или снег) + звук

## 3.  стиль локации

- меняем стиль локации на zx-spectrum (gemini)
- меняем стиль локации на barbi (gemini)
- подставляем в игру новые фоны

### сдаем

1. робота (jpg)
2. своего перпсонажа - рендер + концепт + анимация (jpg 2шт. +  mp4)
3. свой спрайт (jpg)
4. игра (index.html + спрайт.png + bg1.jpg + bg2.jpg)
5. дополнительные фоны (стилизованные)
