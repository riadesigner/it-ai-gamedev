# День 3. LLM-идеация: brainstorm → выбор → копилот

**Продолжение day02** — промпты для **идеации**. Не FSM, не «догонка» базовой сцены.

На day02 у вас уже есть: **игрок + препятствие + враг (patrol / chase / attack)**. Сегодня LLM придумывает **10 новых механик**, вы выбираете **1** и заказываете копилоту добавить в `day02/index.html`.

**Код не открываем.** Только промпты + playtest в браузере.

## Часть A — 10 идей от LLM (~45 мин)

### Шаги

1. Откройте свой `day01-gdd.md` — возьмите **пич** и вспомните, что уже есть в day02.
2. Отправьте **brainstorm-промпт** в LLM-чат.
3. Сохраните **10 идей** в `day03-notes.md`.
4. Улучшите промпт (v2) — если первый список водянистый.
5. **Выберите 1 идею** — запишите, почему (1–2 предложения).
6. *Опционально:* эскиз в image-ИИ.

### Brainstorm-промпт

```text
Ты — геймдизайнер одноэкранных 2D-игр.
Моя игра: {пич из day01-gdd.md}.
На экране уже есть: игрок (WASD), препятствия, враг с режимами patrol / chase / attack.
Придумай 10 НОВЫХ интерактивных элементов для арены — не из моего GDD.
Формат строго:
номер · название · что делает · как игрок понимает за 1 секунду
Без кода. Без повторов. Минимум 3 необычные / безумные идеи.
```

### Критерии ч.A

- [ ] 10 идей скопированы в notes  
- [ ] Промпт v1 и v2 (или обоснование, что v1 сразу хорош)  
- [ ] Выбрана 1 идея + «почему эта»

## Часть B — Заказ копилоту (~45 мин)

### Промпт внедрения

```text
В day02/index.html работают: игрок, препятствия, враг (patrol / chase / attack).
Не ломай их.

Добавь новую механику:
---
{скопировать выбранную идею из списка 10}
---
На экране должно быть видно, что механика работает (подпись, счётчик, цвет, эффект).
Сначала план из 3 шагов, потом правки. Я проверю в браузере (F5).
```

### Промпт-фикс (при необходимости)

```text
После добавления механики:
Вижу: {описание экрана}.
Ожидал: {как должна работать идея}.
Игрок, стены и враг (3 состояния) должны работать как до изменений.
Исправь.
```

### Playtest-чеклист

- [ ] Игрок двигается, стены держат  
- [ ] Враг: patrol / chase / attack — **как на дне 2**  
- [ ] **Новая** механика видна и работает  
- [ ] Могу объяснить идею без открытия кода

## Примеры идей (если LLM выдаёт скучное)

- **Зона замедления** — синий круг, игрок медленнее  
- **Исчезающая платформа** — через 2 сек пропадает  
- **Щит на 3 сек** — враг не видит игрока  
- **Телепорт** — переносит игрока в случайный угол  
- **Липкая зона** — игрок застревает на 1 сек

## Частые ошибки

| Неправильно | Правильно |
| ----------- | --------- |
| «Придумай механики» без контекста | Пич + что уже в игре + формат списка |
| Выбрал идею, но не внедрил | Ч.B обязательна — F5 с новой механикой |
| Сломался враг — сдаю как есть | Промпт-фикс: «враг FSM как на дне 2» |
| Открываю код | Только промпты + playtest |
